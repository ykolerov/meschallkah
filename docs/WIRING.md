# Подключение CP2102 → BIGTREETECH TMC2209 v1.3

Драйвер питается **от двух независимых цепей**: логика VIO = 3,3 В от USB–UART; силовая VM = 24 В от готового DC БП. Все земли объединены. **Ни USB, ни пин +5V CP2102 не питает обмотки мотора.**

## Перед пайкой

1. Сверить **реальную маркировку** модуля с [BTT TMC2209 pinout](https://github.com/bigtreetech/docs/blob/master/docs/TMC2209.md). Описан BTT v1.3, **не произвольный** модуль TMC2209 из магазина.
2. На CP2102 измерить мультиметром между 3V3–GND **≈3,3 В**; проверить, что холостой TXD тоже имеет высокое состояние ≈3,3 В. Адаптер с маркировкой +5V не означает 5-вольтовую логику.
3. Отключить 24 В и USB. Прозвонить четыре провода NEMA17, найти **две обмотки** (~1,5 Ω каждая); не полагаться на цвета проводов.
4. Для BTT v1.3 подтвердить 110 мΩ шунты на плате; не принимать другие Rsense без изменения --rsense.

## Полная таблица соединений

| Источник | Подключить к | Пояснение |
|---|---|---|
| CP2102 3V3 | J2-7 VIO | Логическое питание |
| CP2102 GND | J2-8 GND | Общая земля с БП 24 В |
| CP2102 TXD | через **1 кΩ** к J1-4 PDN_UART | Одна сигнальная линия, резистор в TX |
| CP2102 RXD | прямо к J1-4 PDN_UART | Одна линия, при передаче RX увидит собственный echo |
| CP2102 +5V | **никуда** | Не подключать |
| БП +24 В | J2-1 VM | Проверить полярность |
| БП 0 В | J2-2 GND | Общая земля |
| Конденсатор 100 мкФ/35 В | между VM и GND | Плюс конденсатора к VM, максимально близко к модулю |
| Обмотка A мотора | J2-3 A2, J2-4 A1 | Сначала найти мультиметром |
| Обмотка B мотора | J2-5 B1, J2-6 B2 | Другая пара |
| J1-2 MS1 | GND | UART address 0 |
| J1-3 MS2 | GND | UART address 0 |
| J1-6 CLK | GND | Используется внутренний генератор |
| J1-7 STEP | GND | Не используется в режиме VACTUAL |
| J1-8 DIR | GND | Не используется |
| J1-1 EN | переключатель RUN=GND / OFF=VIO | **Физический выключатель двигателя** |

На некоторых ревизиях BTT разъём J1-5 может быть альтернативным PDN_UART после перестановки перемычки: **в этой схеме используем J1-4**, только если это подтверждает сам модуль.

## Условная UART-схема

~~~text
CP2102 USB-TTL                    TMC2209 BTT v1.3
3V3 ----------------------------> VIO (J2-7)
GND ----------------------------> GND (J2-8) ---- PSU 0V
TXD --[1 kohm]---+-------------> PDN_UART (J1-4)
RXD -------------+
+5V -------------X  do not connect

24V PSU + ----------------------> VM  (J2-1)
24V PSU 0 ----------------------> GND (J2-2)
100uF 35V: positive to VM, negative to GND

EN (J1-1) ---- SPDT ---- GND = RUN / VIO = OFF
~~~

Важное свойство single-wire UART: RXD получает эхо отправленных байтов. Код сначала сверяет это эхо и затем читает ответ TMC2209. Подтверждение записей — по регистру IFCNT.

## Синхронизация со смартфоном: необязательно

Текущий CP2102 имеет только **3V3, TXD, RXD, GND, +5V**. Контактов RTS/DTR на гребёнке нет. Поэтому **по умолчанию запускаем без светодиодного маркера**: без --marker. Все функции управления остаются доступными.

Только если действительно нужен аппаратно синхронизируемый видеоряд:

- Вывести **один** RTS **или** DTR с CP2102 (на QFN это требует микропайки либо поиска существующей площадки). До пайки проверить корпус и распиновку по документации Silicon Labs. Нельзя паять «на глаз» по фотографии.
- Светодиод: **3V3 → 330 Ω → анод LED → катод → RTS/DTR**.
- В кадре камеры должен быть светодиод. При запуске выбрать **--marker rts** или **--marker dtr**. Работу логики и фактическую полярность проверить при выключенном моторе с --dry-run (симулятором переключение физически не проверяется) и отдельно при подключённом адаптере.
- Если диод горит наоборот, использовать --marker-invert. Система фиксирует в CSV timestamp начала/конца записи, но не управляет кнопкой Record на смартфоне.

## Первое включение

1. Блок 24 В **отключён**, переключатель EN в положении **OFF**.
2. Прозвонить VM–GND (нет короткого), проверить электролит, обмотки, ориентацию разъёмов, токовый шунт, радиатор.
3. Подключить USB, определить COM-порт и убедиться в 3,3 В логики.
4. Подключить **24 В**, оставить EN=OFF, выполнить только **check** (коммуникация и регистрация). При необходимости для движения перевести EN в RUN.
5. Запускать вращение только после закрытия магнитного диска кожухом.

**Не подключать и не отключать мотор при поданном VM!** Переключение EN в OFF разрешено и является доступной аварийной остановкой при сбое связи, но не разрывает силовые +24 В.

**Ограничение:** если ПК зависнет или USB кабель отойдёт, драйвер может продолжить последнее VACTUAL. Программа и её обработчики исключений не являются fail-safe контроллером.
